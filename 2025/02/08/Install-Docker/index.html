In this post, we discuss how to install and deploy ScyllaDB on mac

Install Docker with Homebrew

We want to install docker desktop on mac. The homebrew –cask option specifies that Docker Desktop is a GUI application rather than a command-line tool

After install docker, we enable docker built-in kubernetes:

  1. Launch Docker desktop
  2. On top right toolbar, click “Setting” icon
  3. Select “Kubernetes” on the left panel, and turn on “Enable Kubernetes”
  4. Once the image is pulled, restart Docker desktop
